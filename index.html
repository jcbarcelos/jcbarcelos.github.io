Política de Privacidade

Quebra-Cabeça — Jigsaw Puzzle

Última atualização: 04 de julho de 2026

1. Introdução

Esta Política de Privacidade descreve como o aplicativo Quebra-Cabeça ("nós", "nosso" ou "aplicativo") coleta, usa e compartilha informações quando você utiliza nosso aplicativo.

Ao utilizar o aplicativo, você concorda com as práticas descritas nesta política.

2. Dados Coletados

Não coletamos dados pessoais identificáveis. O aplicativo não requer cadastro, login, e-mail ou qualquer informação pessoal para funcionar.

As únicas informações armazenadas localmente no seu dispositivo são:

  • Progresso do jogo (puzzles concluídos, moedas, conquistas)
  • Preferências do usuário (idioma, tema, som)
  • Estatísticas de jogo

Esses dados são armazenados no armazenamento interno do dispositivo (SharedPreferences e FlutterSecureStorage) e nunca são enviados para nossos servidores.

3. Anúncios (Google AdMob)

Este aplicativo exibe anúncios fornecidos pelo Google AdMob. O AdMob pode coletar e usar informações para exibir anúncios personalizados ou não personalizados, incluindo:

  • Identificador de Publicidade do Android (AAID)
  • Endereço IP
  • Dados de uso do aplicativo
  • Tipo de dispositivo e versão do sistema operacional

Você pode optar por não receber anúncios personalizados ajustando as configurações de anúncios do seu dispositivo Android em Configurações → Google → Anúncios ou através das configurações de privacidade do AdMob.

Para mais informações sobre como o Google coleta e usa dados, consulte a Política de Privacidade do Google e os Termos de Consentimento do Usuário da EEE do Google .

4. Serviços de Terceiros

O aplicativo utiliza os seguintes serviços de terceiros:

  • Google AdMob — exibição de anúncios

6. Permissões do Dispositivo

O aplicativo pode solicitar as seguintes permissões:

  • Internet — necessária para carregar anúncios e funcionalidades de backup
  • Notificações — para lembrete do puzzle diário (opcional, configurável)

7. Segurança dos Dados

Os dados armazenados localmente no dispositivo são protegidos pelo sistema operacional Android. Não transmitimos, vendemos ou compartilhamos seus dados com terceiros, exceto conforme necessário para os serviços de anúncios descritos acima.

8. Direitos do Usuário

Você tem o direito de:

  • Acessar — solicitar informações sobre os dados armazenados
  • Excluir — desinstalar o aplicativo para remover todos os dados locais
  • Opt-out de anúncios personalizados — conforme descrito na seção 3

9. Crianças

O aplicativo é adequado para todas as idades, incluindo crianças. Não coletamos intencionalmente dados pessoais de crianças. Os anúncios exibidos podem ser configurados como não personalizados para cumprir com a COPPA, a critério do desenvolvedor no console do AdMob.

10. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente. Recomendamos revisar esta página regularmente. Alterações significativas serão notificadas através do aplicativo.
